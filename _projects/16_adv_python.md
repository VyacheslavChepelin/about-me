Курс **«Продвинутый Python»** (classroom GitHub, репозитории приватные). Инструменты: `uv`, `pytest`, `ruff`, CI.

## Домашние задания

### ДЗ 1 — Модель данных, CLI, пакетирование
Контейнер и CLI, entry points в `pyproject.toml`, пакетирование.

### ДЗ 2 — Функциональное программирование и декораторы
- Система декораторов (`@validate_types` + декораторы по варианту)
- Пайплайн: `pipe`, `compose`, `filter_by`, `sort_by`, `take`
- Публикация библиотеки на TestPyPI

### ДЗ 3 — Углублённое ООП и дескрипторы
- Класс `Matrix` (арифметика, hash, контекстный менеджер)
- Дескрипторы атрибутов
- Хеширование и коллизии в `set` / `dict`

### ДЗ 4 — Многозадачность и синхронизация
Потоки/процессы: Fibonacci, численное интегрирование, потокобезопасный логгер.

### ДЗ 5 — Асинхронное программирование
`asyncio`: исправление async-кода, downloader, пайплайн обработки.

### ДЗ 6 — Профилирование и оптимизация
Профилирование (Scalene), ускорение «узких мест» (матрицы, нормы), отчёт с замерами.

## Стек

Python 3 · uv · pytest · ruff · GitHub Classroom / CI
