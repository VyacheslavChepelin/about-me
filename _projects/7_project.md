Школьный проект: парсинг и генерация заданий из открытого банка ФИПИ / РешуЕГЭ с Telegram-ботом и GUI для занятий.

### Цель

- Автосбор заданий ЕГЭ (орфоэпия и др.)
- Структурирование данных для тренировок
- Бот для загрузки в базу и GUI для проведения занятий

### Запуск

- `python bot_main.py` — Telegram-бот
- `python gui_main.py` — интерфейс для занятий
