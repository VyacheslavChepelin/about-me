Командная лабораторная ИТМО (Чепелин, Свешников, Хасанов). Публичной ссылки нет.

## О чём работа

Методы для **условных** и **негладких** задач оптимизации.

### Методы

- Субградиентный метод
- Proximal gradient и ускоренный proximal FGM
- **Frank–Wolfe**
- Барьерный метод
- Циклический coordinate descent (log-cosh / exp-loss)

### Эксперименты

- Способность методов давать строгую разреженность
- Сравнение методов с подсчётом оракульных вызовов
- Задачи на LIBSVM-датасетах

Python · NumPy · Jupyter · pytest
